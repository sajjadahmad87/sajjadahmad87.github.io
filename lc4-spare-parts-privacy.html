Privacy Policy - LC4 Spare Parts

Effective date: 20 August 2026

LC4 Spare Parts is designed as an offline spare-parts reference and Excel workbook viewer. The app does not require user accounts, does not include advertising, and does not transmit a user-selected Excel workbook or its contents to an external server.

Data access and use

The app accesses an Excel file only after the user explicitly selects it through Android's system file picker. The selected file is processed locally on the device to provide stock, search and workbook-viewing functions.

Data collection and sharing

This version does not collect or share personal data off the device. It contains no analytics or advertising SDKs and does not request location, contacts, camera, microphone, SMS, call logs, or broad all-files storage access.

Retention and deletion

The app stores only the Android document reference/permission required to reopen the selected workbook. The user can remove this access by clearing the app's storage, uninstalling the app, or selecting another workbook.

Security

The app is designed to keep workbook processing on the user's device and does not implement an external data-transfer service in this version.
